The videos show the team's application with fictional data in isolated browser sessions. The full presentation uses the original demo; the short presentation uses the extended case. Presentation cards accompany actual application footage. Both MP4s include synthetic English speech and burned-in English subtitles, encoded as H.264 video and AAC audio. Team names and credits are retained.

These are software demonstrations, not evidence of clinical effectiveness. No real personal records or original research files are included. Communication with Earth is simulated. The short video is provided as a presentation asset; its inclusion does not certify compliance with an event submission requirement.
