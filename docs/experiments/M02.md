## Refuted and surprises

SOURCE: The orchestrator confirmed half-open phase intervals [from,to), overlap rejection and explicit equipment membership during implementation, and will document the cross-module policy in contracts 0.6. No shared contract file was changed by this builder.
READ: No catalog lookup dependency exists in the M02 contract. hasEquipment checks explicit list membership and rejects malformed configs; it cannot prove an arbitrary listed equipment ID exists in an external catalog. Unknown/not-listed IDs return false.

RUN: Independent review exposed two acceptance-oracle gaps: a mutant rejecting an empty equipment list and one rejecting finite negative bounds both survived the original tests, although the unmutated implementation handled them correctly. Added exact acceptance/preservation assertions (empty equipment, low=-1/high=0); each of the same two mutations now yields exit 1 on assertion and the restored implementation still passes 10/10. No production behavior was changed to satisfy these tests.
