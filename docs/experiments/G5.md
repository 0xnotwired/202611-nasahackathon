## Refuted and surprises

- **Refuted:** the first draft of W1 predicted that M22 would refuse a file typed under the synthetic subject's identifier. It does not: M22 isolates by store, by design (M22-P1/X5). The claim that matters, that no synthetic view changes, holds and is now tested with that identifier too.
- The comments the gate guards against exist only in CRF, which the user discarded and M22 lists as unsupported; the supported adaptation and glucose files carry none, and an extra comment column is dropped by the importer's allow-list. W3 therefore checks CRF at the importer and an adaptation file with an extra comment column through the view.
