Scope: app/importers/ and this record. No later-phase gate acceptance,

## Predictions (before implementation)

- M21-P1: Original CRF numeric values survive import exactly; unknown units are explicit.
- M21-P2: Empty/NA/NaN cells produce not_recorded without value, never0.
- M21-P3: Source identifier007 remains text007.
- M21-P4: Malformed row between valid rows is rejected with bounded row/field reason; valid rows survive.
- M21-P5: Nonempty clinical comment cells are skipped/countable, never copied into output.
- M21-P6: NASA records retain ground_analog origin, subject, phase and day context.
- M21-P7: Acquired originals compared row-by-row in a separate real-file validation run.
- M21-P8: BUT CGM glucose mmol/L and missing state are preserved; terrestrial origin and citation retained.
- M21-X1: Quoted delimiters/newlines/escaped quotes parse, hostile header/invalid options rejected without getters.
- M21-X2: Unknown-zone/date-only/minute/shifted source clocks preserve precision, never invent UTC.
- M21-X3: Schema2 core accepts every output; unsupported relative/aggregate/omics studies fail explicitly.
- M21-X4: Source SHA256, row and variable generate stable file-scoped IDs; batch bounds fail rather than truncate.

RUN: The original synchronous SHA256 was checked against the published abc

RUN: `/tmp/m21-real-check.mjs` reads five actual acquired originals and compares
every selected numerical cell with its corresponding imported value/state;
checks source SHA256 with Node crypto, core validation and unique IDs.
CRF:791 records,226 excluded nonempty comment cells; MR079G:12 records;
MR035G:10; exact-test MR080G:32; BUT CGM:3016. All zero row rejections.
The source cells marked NA in the excluded free-text fields count as nonempty
skipped cells too; their content never enters any output. The real-file
assertions are local validation, not shipped raw-data fixtures.

READ: Public functions are synchronous/pure and produce no database writes,
DOM access, clock calls, random IDs, network requests or external messages.
All source IDs stay strings. File SHA256 plus subject SHA256, physical source
start line (including header), and numeric-column ordinal form record IDs.
No malformed UTF16 can collapse a caller identity or source text into U+FFFD.
This is provenance and deterministic identity, not source authentication.

READ: Inputs are bounded to5MiB UTF8,64 columns,16384 characters per cell,
10000 potential output records and bounded context text128 characters.
Malformed syntax/header and exceeded bounds return explicit failures; row
shape/numeric/context/calendar errors return bounded rejection entries.
Unknown headers never override profile-specific identity/context fields.
Unclosed quotes fail the whole text because continuation boundaries cannot
be determined safely. Decimal canonicalization rejects rounding/underflow
that would change a source decimal, not a medical range. Nonempty free-text
clinical cells produce only row/column/reason entries in skipped.

READ: CRF/MR035G retain explicit unknown units where source metadata is
unconfirmed; no interpretation or conversion occurs. Dates use schema2
source_time with unknown zone and original precision, not fabricated UTC.
BUT CGM retains its shifted per-participant calendar. MR080G unit mappings
are scoped to C3C/7772/2006-05-07 and exact Test name; VE retains BTPS.
Relative-axis, aggregate and omics studies fail unsupported_study rather
than being forced into individual health records.

RUN: Full Node suite at builder handoff ran100 tests,98 passed and2 failed in

## Refuted and surprises

The initial profile copied all CSV headers before selecting aliases; an
unknown column could override the MR035G uppercase subject/phase/day fields.
This was refuted by explicit parent controls; only the declared whitelist
now populates a profile row. The initial numeric parser preserved finite
Number values but could underflow or round source decimals; the regression
now rejects those cases explicitly. File-only record IDs were insufficient
when the caller assigned identical glucose bytes to a second participant;
subject-bound IDs fix this. UTF8 replacement of invalid surrogate input was
another identity alias; malformed UTF16 is now rejected before encoding.

## Not verified

No clinical correctness, physiological equivalence or source-unit metadata
recovery is claimed. No UI/permission/session workflow, source-provider
approval or unrestricted arbitrary study mapping is implemented. Raw files
remain ignored; this module does not implement packaging. Neither genotype
normalization nor a general environmental/relative-time model was added.
The caller controls persistence; parent tests exercise the real store/browser.

Applied skills: validate-at-the-boundary and falsifiable-testing; the named
untrusted-sample-handling skill was read and its no-execution rule respected,
without representing ordinary data files as malware. Product code is original;
only mathematical SHA256 constants/operations are used, no copied helper.
OpenAI Codex authored implementation/tests; no commit/push was performed.
