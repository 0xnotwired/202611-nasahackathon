## Interpretation decisions (not contract changes)

- **D-M22-1 Interactive state lives in the view model.** The shell calls `model(services, params)` once and `mount(element, viewModel, actions)` with no services. The model therefore returns closures (`interactions.loadFile`, `interactions.select`) that keep a session and return the next view model; `view.js` only draws and calls them.
- **D-M22-2 Imported records stay in a private store.** `services.openMemoryStore()` opens a memory store used only by this view. Nothing is written to `services.store` (R9), and nothing persists after the page closes.
- **D-M22-3 CRF is discarded for now.** On the user's instruction. The loader lists it as unsupported with its reason instead of hiding it.
- **D-M22-4 Wiring outside the owned paths** (authorized): `app/ui/base/start.js` adds `importers` and `openMemoryStore` to the services; `tests/contract/registry.js` and `foundation.test.js` treat implemented views as a separate list, because a view cannot satisfy `checkView` without a DOM.
- **D-M22-5 Profile table is data with provenance.** Citations and licences are copied from the repository's attribution documents, read in this session (SOURCE, full text). The BUT CGM sampling interval comes from its README (SOURCE, full text, 2026-11-15).

## Refuted and surprises

- **Refined before the run (not a result): the work order's P2 wording.** "Says ground analog" would be false for BUT CGM (origin `terrestrial`). Reported to the orchestrator; the view uses each record's own origin label.
- **Surprise 1: three tests of mine were wrong.** X6/X7 expected the initial selection, but `interactions` share one session, so an earlier `select` had already changed it; the view model correctly keeps the *previous* selection when a day or subject list is refused. X8 called `JSON.stringify` on an accessor-trap object inside its own assertion message, which ran the getter (the same mistake as in M06). Rival explanations for each: a model bug vs a test bug. The failing values (`'2100-01-02'` instead of `'2100-01-01'`, a missing `'B'` after `["A","A"]`, `accessor ran` thrown from the test file) pointed to the tests; the model was unchanged.
- **Surprise 2: two browser-check mistakes of mine.** The rejected-rows selector also matched the chart's table, and the origin check forbade "ground analog" on the whole page although the page notice legitimately says "ground analogs". Both were corrected in the script, not in the view.
- **Surprise 3: the shell could not draw a chart for a view.** `renderChart` and `renderTable` lived in `base/dom.js`, which is not part of the module's single door. Rival designs: import the internal file (breaks the single-door rule) or export three DOM renderers from `base/index.js`. The second was chosen and written into contract 0.11.
- **No prediction from the work order was refuted except the P2 wording above.**
