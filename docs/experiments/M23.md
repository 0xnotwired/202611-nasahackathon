## Decision details

| Decision | Alternative rejected | Reversibility | Revisit when |
|---|---|---|---|
| Each module is embedded as text and created as a `blob:` ES module at start, in dependency order | Rewriting `import`/`export` into one script (regex rewriting of live bindings is the likelier way to change behaviour); an import map with `data:` URLs (relative imports inside them do not resolve) | Two-way | A browser the team presents on refuses blob modules under the policy |
| A content security policy, `default-src 'none'; script-src 'unsafe-inline' blob:; style-src 'unsafe-inline'; img-src data:` | Promising there is no remote load and checking only by reading code | Never | Never |
| Only the specifier syntaxes the codebase uses are rewritten, and any other import form fails the build | A JavaScript parser (a dependency, which needs named approval) | Two-way | A new import form appears |
| `mission/index.js` is not packaged (nothing imports it) | Packaging every file | Two-way | Running code imports it |

## Runs

- RUN: 5 tests red (no packager), then green after one invariant of mine was corrected: the first draft asserted more than 60 modules, a number I had not counted (the file holds 59 reachable modules); it now asserts that every module folder is packaged except `mission`, named openly. A second correction: the first import-detecting expression crossed lines and mistook a string containing `from ", "` for an import; it now accepts only real import and export clauses.
- RUN: `node scripts/package.mjs` gives `dist/orbita.html`, 59 modules, 364,419 bytes, deterministic.
- BROWSER (`tests/walkthrough/g6-browser.py`, G6): see G6.

## Negative controls

Scratchpad `mutate-g6.mjs`: a relative import left as a file path (P1), a view folder not packaged (P1b), a policy that allows any script source (X2) or connections (X2b), a cycle not detected (X3), a missing file not detected (X3b), a remote import accepted (X3c) and the dynamic import left alone (X4) each go red. **X3b and X3c were not caught at first, because a second layer also failed the build** (reading a missing file throws); the tests now pin each defence's own message, and then both go red.

## Refuted and surprises

- Refuted: M23-P3 "the same results line by line" was false at the first run: the summary text carries the episode's random id, which differs on every run in either mode. The comparison now normalizes UUIDs, and nothing else.
- Tooling: Playwright's `wait_for_function` evaluates text inside the page, which the packaged file's policy forbids (correctly). The script polls with `evaluate` instead.

## Not verified

- Only Chromium. Firefox, Safari and Edge were not run: whether each accepts blob: modules under this policy, and whether IndexedDB works from `file://` there, is open (M23-P4 asks for each browser the team presents on).
- Whether data saved from `file://` is found again when the file is moved or opened by another path (the origin of a `file://` page is opaque) was not tested.
- Keyboard walks were run on the served app; on the packaged file only the G6 script (ten views and the episode journey) was run.
- The size (364 KB) and start time of the packaged file were not measured against a budget.
