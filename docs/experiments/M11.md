## Runs

- RUN: stub red (6 of 7 failed), then 7/7 green on the first implementation. Because green came first try, controls were run before trusting it.
- BROWSER: the variable select works by keyboard; the chart table opens by keyboard and says "not recorded" for the empty day.
- A screenshot showed two defects the tests did not: a comparison for an absent variable repeated its label, and the timeline showed raw ids such as `sleep_hours`. Both fixed, then 230/230.

## Refuted and surprises

Observation: a 30-day chart with few readings draws a dashed mark for every empty day, which is honest but visually busy. Left as is for a person to judge.

## Not verified

The 30-day chart window is a display choice, not a health value. The baseline is a count, period and range with no judgement; nobody has reviewed whether that wording helps a person.
