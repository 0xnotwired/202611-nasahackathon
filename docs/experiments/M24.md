## Decision details

| Decision | Alternative rejected | Reversibility | Revisit when |
|---|---|---|---|
| The link follows `MissionConfig.communication`; `delayed` has no number in the configuration, so the person sets the delay in minutes | A default delay (an invented number) | Two-way | The configuration carries a delay |
| A `delayed` configuration with no delay puts the link down, shown as "delayed: the link is down until a delay is set" | Leaving the previous mode up (found by a browser walk and a test: a switch from a live link would have delivered) | Never | Never |
| `deliveries` is an extra export so a sender can see queued and in-transit items | Reading the store from the view | Two-way | The contract names a different door |
| Enqueuing the same share twice returns the same delivery | Two deliveries | Two-way | Re-sending becomes a feature |
